# Publication Strategy

1. Informal specialist review  
2. Preprint with code + certificates  
3. Peer-reviewed publication  
4. Independent reproduction  
5. Response to objections  
6. Version registry  
7. Disclose human vs AI assistance per venue rules  

**Do not** send putative Clay solutions directly to CMI before specialist review.  
**Do not** contact press before specialist review.  
**Do not** use “Navier–Stokes solved” in preliminary titles.
